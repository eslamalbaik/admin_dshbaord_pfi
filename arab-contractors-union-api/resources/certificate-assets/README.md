# أصول شهادة العضوية

مصادر الهوية البصرية لشهادة العضوية المولَّدة بـ`MembershipCertificatePdfService`.

## القالب (التصميم المعتمد 2026-11-08)

`membership-certificate-template.pdf` هو ملف المصمم "شهادة عضوية 3" (Illustrator) نفسه،
بعد حذف كل ما يتغيّر من شهادة لأخرى. يستعمله mPDF خلفيةً (`SetDocTemplate`) ويكتب فوقه.

يبقى فيه: الترويسة والتذييل والعلامة المائية، عنوان "شهادة عضوية" وزخرفته، سطر
"يشهد اتحاد المقاولين الفلسطينيين بأن"، كلمة "التاريخ:"، شريط رأس الجدول، الختم وخط التوقيع.

حُذف منه (ويرسمه الكود): قيمة التاريخ، اسم الشركة، سطر رقم العضوية والعنوان، سطر قرار
التصنيف، صفوف الجدول وخطوطه، سطر الصلاحية، اسم النقيب وصفتاه، الـQR ونصوصه.

لو أرسل المصمم نسخة معدّلة: احذف منها نفس العناصر المتغيّرة (أو اطلب منه نسخة بدونها)،
وتأكد أن مواضع الجدول لم تتغيّر — إحداثياته مثبّتة في الخدمة.

## الخطوط

خطوط التصميم الأصلية (`DIN Next LT Arabic` و`zain-mob`) تجارية وغير متوفرة لدينا،
فاستُعمل أقرب بديل مجاني (رخصة OFL، من Google Fonts):

| الملف | بديل عن | يُستعمل في |
|---|---|---|
| `IBMPlexSansArabic-Regular.ttf` / `-Bold` | DIN Next LT Arabic Regular/Bold | سطر القرار، الصلاحية، صفتا النقيب، الأرقام العريضة |
| `IBMPlexSansArabic-Medium.ttf` | DIN Next LT Arabic Medium | الجدول، سطر العضوية، التاريخ، اسم النقيب |
| `Zain-Black.ttf` | zain-mob | اسم الشركة |

العنوان وسطر "يشهد…" مطبوعان بالقالب بالخطوط الأصلية نفسها. لو توفرت ملفات DIN وzain
الأصلية يكفي تبديل الملفات في تعريف `fontdata` بالخدمة.

**لماذا لا أميري ولا Noto Naskh:** كلاهما يحوي جدول `GPOS Lookup Type 5, Format 3`
غير المدعوم في محلّل OpenType بـ mPDF، فيرمي `FontException`. لذلك يبقيان مستثنيَين في `.gitignore`.

**ذاكرة mPDF المؤقتة:** mPDF يخزّن بيانات كل خط تحت اسمه في `storage/app/mpdf-tmp/ttfontdata`.
عند تبديل ملف خط احفظه باسم مفتاح جديد في `fontdata` (أو امسح الذاكرة)، وإلا قرأ بيانات
الملف القديم ورمى `Uninitialized string offset`.

## أصول قديمة غير مستعملة حالياً

`letterhead-*.png` و`union-seal.png` وخطوط `PTBoldHeading` و`Calibri` و`TimesNewRoman` و`Arial`
كانت للتصميم السابق (ترويسة Word). لم تعد الشهادة تستعملها.

## لماذا mPDF أصلاً

سيرفر cPanel الإنتاجي لا يحوي LibreOffice ولا يمكن تثبيته بلا صلاحيات root،
فمسار DOCX→PDF يفشل هناك. mPDF حزمة PHP خالصة تعمل في أي بيئة.
