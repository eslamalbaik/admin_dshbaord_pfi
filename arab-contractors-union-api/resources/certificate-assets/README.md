# أصول شهادة العضوية

مصادر الهوية البصرية لشهادة العضوية المولَّدة بـ`MembershipCertificatePdfService`.

## الصور

مستخرَجة من قالب Word المعتمد `resources/templates/membership_certificate.docx`
(من `word/media/`)، فتبقى مطابقة للمصدر الرسمي:

| الملف | الأصل | الأبعاد | الموضع |
|---|---|---|---|
| `letterhead-header.jpg` | `image2.jpeg` | 2481×621 | ترويسة الصفحة |
| `letterhead-footer.png` | `image3.png` | 2481×381 | تذييل الصفحة |
| `union-seal.jpg` | `image1.jpeg` | 479×477 | بجانب التوقيع |

## الخطوط

الشهادة تستخدم **خطوط القالب الأصلية نفسها** المشحونة في `fonts/`:

| الملف | يُستعمل في |
|---|---|
| `PTBoldHeading.ttf` | عنوان "شهادة عضوية" واسم الشركة |
| `TimesNewRoman.ttf` + `-Bold` | سطر "يشهد اتحاد المقاولين..." |
| `Arial.ttf` | متن جدول المجالات والتخصصات |
| `Calibri.ttf` + `-Bold` | باقي المتن والتذييل والتوقيع |

**لماذا تُشحن مع المستودع:** سيرفر Linux الإنتاجي لا يحوي هذه الخطوط، وبدون
وجود الملفات فعلياً في هذا المجلد يرمي mPDF‏ `FontException` ويفشل توليد الشهادة
كلياً. لذلك استُثنيت من `.gitignore` عمداً.

> **تنبيه ترخيص:** `PT Bold Heading` و`Arial` و`Times New Roman` و`Calibri` خطوط
> مرخّصة تجارياً مع Windows/Office ولا يُصرَّح بإعادة توزيعها عموماً. شُحنت هنا
> بقرار صريح من الاتحاد لتحقيق مطابقة الشهادة للقالب المعتمد. قبل نشر المستودع
> علناً أو خارج الاتحاد يجب مراجعة هذه النقطة.

**لماذا لا أميري ولا Noto Naskh رغم أنهما مفتوحان:** كلاهما يحوي جدول
`GPOS Lookup Type 5, Format 3` وهو غير مدعوم في محلّل OpenType بـ mPDF، فيرمي
`FontException` عند التوليد. تعطيل `useOTL` يتفادى الاستثناء لكنه يلغي ربط
الحروف العربية فيخرج النص متقطّعاً. لذلك يبقيان مستثنيَين في `.gitignore`.

## لماذا هذه الأصول أصلاً

سيرفر cPanel الإنتاجي لا يحوي LibreOffice ولا يمكن تثبيته بلا صلاحيات root،
فمسار DOCX→PDF يفشل هناك. mPDF حزمة PHP خالصة تعمل في أي بيئة، لكنها تحتاج
الترويسة والتذييل والختم كصور — وهذا ما يوفّره هذا المجلد.
